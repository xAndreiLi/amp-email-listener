### Resend Inboxes is a private-beta hosted alternative to this package's spool plus session: it gives an address on a domain the user has verified, threads, labels, drafts and reply/forward/send-draft operations, and can receive without an MX record through `forwarding: true` — so the same address can carry both halves of the loop, at the cost of owning a domain and depending on a beta whose response shape may change.
Kind: fact
Evidence:
- source: https://resend.com/docs/api-reference/inboxes/create-inbox.md — "Inboxes are currently in private beta and only available to a limited number of users. The response shape might change before GA."
- source: https://resend.com/docs/api-reference/inboxes/create-inbox.md — "An inbox sends and receives email at an address on one of your domains, such as `[REDACTED_EMAIL]`."
- source: https://resend.com/docs/api-reference/inboxes/create-inbox.md — "When `true`, Resend provisions a receiving address so you can receive mail without adding an MX record."
- source: https://resend.com/docs/mcp-server.md — "Search their threads, and manage threads, thread emails (get, reply, forward), labels, and drafts (create, update, send)."

### Resend ships a hosted MCP server that gives an agent send, list, cancel and read-email tools with no code written by this package, which is the smallest possible way to add a mail capability to a session — and the one that bypasses the package's quarantine, since MCP tools are ordinary tools available in any session.
Kind: fact
Evidence:
- source: https://resend.com/docs/mcp-server.md — "Resend's MCP server gives your AI agent native access to the full Resend platform through a single integration."
