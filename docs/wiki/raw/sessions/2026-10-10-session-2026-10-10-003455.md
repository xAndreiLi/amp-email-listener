### Resend's own agent-inbox model answers the send question with drafts: an inbox's `enabled_actions` may include `draft_reply`, `forward_thread`, `add_labels`, `assign_thread`, `mark_as_spam`, `archive_thread` and `delete_thread`, and the list contains no send action. The same documentation's agent guidance ranks a strict sender allowlist first of five security levels — a gate this package deliberately does not have (decision c1), so that posture would reverse a decision rather than extend it.

### Threading an agent's reply on Resend is header work, not an API feature: the caller sets `In-Reply-To` to the received `message_id` and appends it to `References` for repeat replies, using custom headers on the ordinary send call. `Idempotency-Key` (unique per request, expires after 24 h) is what makes a retried send after a crash safe.
